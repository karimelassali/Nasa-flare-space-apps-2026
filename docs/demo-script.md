# Reliable 2–3 minute demo

0:00–0:25 — Open Research Agent. Explain that FLARE is a source-linked research workspace with explicit gaps and an illustrative 3D view.

0:25–1:10 — Ask “Compare SAFFIRE-I and SAFFIRE-III.” Open the comparison action. Show 1.8 versus 2.3 mm/s and 420 versus 300 s. These values were rechecked in NTRS 20180005168, Table 1 slides 30–31. Explain that geometry/conditions still matter and absent uncertainty is not zero. Show the oxygen ranges rather than claiming identical atmospheres.

1:10–1:45 — Open Knowledge Base, search FLEX-008 (or EV-PSI69-01), open Details and NASA Source. Show the 14.8 s burn duration and Disruption end condition from Table IX, printed page 20. Download JSON and Markdown; open their contents.

1:45–2:20 — Open 3D Simulation. Load FLEX, change camera, pause/play, toggle chamber shell. State that this is conceptual animation, not measured flame geometry or validated CFD. Export a snapshot carrying that disclosure.

2:20–2:45 — Show evidence gaps and source review labels. State that SAFFIRE-V has unresolved publication differences and overview records do not supply missing measurements. If AI is unavailable, explain the displayed deterministic mode; the same local evidence remains available.
